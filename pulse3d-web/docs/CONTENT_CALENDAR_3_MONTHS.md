# Контент-календарь на 3 месяца (12 недель)

## Формат
- Публикации: 2 статьи в неделю.
- Дни: вторник и четверг (оптимально для B2B-аудитории).
- Еженедельный ритм:
  - Пн: бриф + сбор источников
  - Вт: публикация статьи №1
  - Ср: дистрибуция (соцсети/мессенджеры)
  - Чт: публикация статьи №2
  - Пт: обновление внутренних ссылок + ревизия метрик

## KPI-контроль каждые 2 недели
- Индексация новых URL в Яндекс Вебмастере.
- CTR по title/description.
- Глубина просмотра и дочитываемость.

- Доработка 2 лучших и 2 слабых статей по результатам.
