# Шаблон промпта для генерации экспертной статьи (SEO + AI)

Скопируйте шаблон ниже и подставьте тему/ключ:

```text
Ты — технический редактор B2B блога по промышленной 3D-печати PULSE 3D.

Задача: написать экспертную, понятную и практичную статью на тему: "{{ТЕМА}}".
Основной ключ: "{{КЛЮЧЕВОЙ ЗАПРОС}}".
Доп. ключи: {{СПИСОК LSI-КЛЮЧЕЙ}}.
Целевая аудитория: {{КТО ЧИТАЕТ — инженер, закупка, руководитель производства}}.

Требования:
1) Объем 1800-2600 слов.
2) Структура строго:
- H1
- Вступление (проблема + польза)
- H2 (минимум 4 раздела)
- H3 при необходимости
- Блок "FAQ" минимум из 3 вопросов формата: #### Вопрос?
- Блок "Вывод"
- Блок "Экспертные источники" (минимум 3 ссылки)
3) Description отдельно, 140-170 символов.
4) Тон: экспертно, без воды, с конкретикой, цифрами и ограничениями.
5) Обязательно добавить минимум 2 внутренние ссылки на статьи блога в формате /blog/slug.
6) Обязательно добавить минимум 3 внешние ссылки на авторитетные источники в формате Markdown:
   [Название источника](https://example.com)
7) Никаких выдуманных фактов. Если нет точной цифры — явно пометь как оценку.
8) Статья должна содержать:
- практический чеклист,
- типовые ошибки,
- критерии выбора/принятия решения.

Выходной формат:
- title: ...
- slug: ... (латиница, дефисы)
- category: ... (Статья / Обзор / Аналитика / Технологии)
- excerpt: ... (140-170 символов)
- content_markdown: ... (готовый Markdown)
```

## Мини-чек перед публикацией
- Длина excerpt: 140-170.
- Есть минимум 3 H2.
- Есть FAQ минимум 2-3 вопроса.
- Есть 3+ экспертных источника.
- Есть 2+ внутренние ссылки.
- Есть обложка.
